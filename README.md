## 👨‍💻 Sobre mí

- 🎓 **Estudiante de Ingeniería en Software** en Baja California, México
- 💼 Desarrollador web en **[SolveTech](https://solvetech.mx/)**, agencia de diseño web en Tijuana
- 🌐 Creo sitios web y landing pages rápidas con **HTML, CSS y JavaScript** puro, desplegadas en **Cloudflare Pages**
- 📱 Desarrollo **PWAs offline-first** como [SERIE](https://github.com/Salereee/SERIE), un registro de rutinas de gimnasio
- 🤖 Experimento con **Python** y automatización, como un [bot de trading](https://github.com/Salereee/crypto-bot) con filtro LLM
- 🚀 Siempre aprendiendo nuevas tecnologías y mejorando mis proyectos
